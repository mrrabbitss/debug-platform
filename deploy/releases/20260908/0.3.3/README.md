# 0.3.3 内网识别码登录包

本版需要同时更新服务器和分机：

- `GWAP-Debug-Server-Setup-0.3.3-x64.exe`：920,864,664 字节，包含完整运行时和模型。
- `分机快速安装包.zip`：44,249 字节，内置本次部署地址。
- [服务器指南](../../../../docs/服务器使用指南.md)与[分机指南](../../../../docs/分机使用指南.md)。
- [SHA256.txt](SHA256.txt)：两个交付文件的校验值。

先安装并启动服务器，再安装分机。个人识别码为一位小写字母加八位数字，首次输入后自动开通工程师身份。
无需团队接入码、手工令牌或手工填写服务器地址。分机安装器自动配置当前用户的证书，网页可接续 CLI 身份。

同一码对应同一账号，属于内网互信的自报身份方式；管理员仍从独立入口登录。

专用包包含部署地址，只在本地交付，不存入 Git。文件位于 `artifacts/lan/simple-login-0.3.3/delivery`。
本次仅检查新增身份流程并完成构建，没有重复历史回归；公司实机连接尚待验收。

# 分机使用指南

适用于 0.5.0 配套内网分机包。电脑需已有能正常使用的 CodeAgent。

## 安装

1. 先确认服务器已启动，完整解压分机 ZIP，双击 `Install.bat`。
2. 输入自己的个人识别码：**一位小写字母＋八位数字**，例如 `a12345678`。
3. 完成后，桌面会出现 `GWAP Platform` 和 `GWAP CodeAgent`。

服务器地址已经预置。安装器自动取得服务器公共证书，保存到当前 Windows 用户下；如果 Windows 弹出证书确认，确认后继续。不需要填写服务器地址、指纹、团队接入码或个人令牌。
安装中断后可重新运行 `Install.bat`，已保存的身份会继续使用。

## 日常使用

- **网页**：双击 `GWAP Platform`，自动以自己的身份登录。
- **CLI 分析**：双击 `GWAP CodeAgent`。首次找不到 CodeAgent 时，选择其启动文件，例如 `C:\Tools\CodeAgent\codeagent.cmd`；不要填 `codex.exe`。
- **直接用浏览器打开服务器**：首次输入同一个个人识别码，之后会记住登录。

CodeAgent 中先输入：

> 使用 gw-ap-debug 检查平台连接。

然后提交分析请求，例如：

> 使用 gw-ap-debug 分析 AP 离线问题。GW 日志在「完整路径」，AP 日志在「完整路径」。请创建案例、分析日志并生成报告，结论引用日志证据。

CodeAgent 自身的模型登录继续使用你原有的配置。网页在“系统设置”添加自己的诊断 API 或选择共享模型，
个人选择统一用于自己的诊断、问答和 AI 提炼；没有选择时跟随共享默认。API Key 仅由服务器保管，不向其他用户显示。

普通用户左侧为“故障定位、知识库、系统设置”；专家和管理员另有直接的“知识库管理”入口。
新案例先选问题类别，包括管理角色新增的类别；不确定时选“未知”。
模型出站同意对新案例默认开启，可自行关闭；历史关闭设置不变。
报告保留逐设备时间轨迹与分层推理；疑问可在案例内继续问答，确定后提交定位结果和报告供管理员或专家确认。

## 身份和知识使用

请始终使用自己的识别码。同一码在网页、CLI 和不同电脑上对应同一个账号；它是身份标记，不是密码，不要使用别人的码。

管理员在“系统设置 → 安全与审计”将现有账号改为 EXPERT 后，继续用原识别码进入。
0.5.0 分机首次登录、凭据复用和网页登录票据均支持专家身份；新识别码自助注册只创建 ENGINEER。
ADMIN 和停用账号不能通过识别码及分机网页登录入口登录；管理员继续使用管理员令牌入口。

普通用户可查看已发布 Skill、Markdown、共享案例和报告，管理自己的知识草稿、上传案例与 Wiki Markdown，
使用 AI 案例提炼；可提出共享知识修改/删除和 Skill 修改建议，由管理员或专家审核后发布。
模型诊断必读的 Skill 仅管理员和专家可直接管理。已诊断案例与报告审核确认后进入共享库。

换电脑时重新安装并输入同一码即可。在当前电脑切换身份，在分机目录打开 PowerShell 执行：

```powershell
.\Start.bat -Configure
```

随后从桌面重新打开网页。网页右下角也可单独切换账号。

## 升级与慢模型等待

先由管理员升级服务器，再完整解压 0.5.0 分机 ZIP，运行 `Install.bat` 并使用原识别码。
新版包含专家身份支持和更长的 CLI 平台请求等待；原有 ZIP 文件不会自动更新。

网页单次模型请求默认 15 分钟，网页同步 AI 请求和 CLI 平台长工具允许等待 2 小时。
后台任务可以查看进度和取消；模型排队时不要重复提交。CodeAgent 自身模型由其配置和上游服务管理，
平台不能覆盖公司网关设定的更短超时或修复上游 500。
配套启动器为兼容 Claude Code 的 CodeAgent 设置至少 15 分钟的请求及流等待，并为平台工具设置 2 小时；
已有更长请求等待值保留。原生 Codex 使用项目 MCP 安装脚本更新，平台工具等待为 2 小时；
自身模型流等待可在实际 provider 配置中设置 `stream_idle_timeout_ms = 900000`。
原生 Codex / Claude 的 MCP 安装脚本也位于新版 ZIP 的 `scripts` 目录，供已配置平台地址和个人令牌的用户使用。
桌面 `GWAP CodeAgent` 继续使用 CodeAgent，不要把原生 Codex 当作 CodeAgent 启动文件。

## 遇到问题

- 连接失败：确认服务器已启动、公司网络可达；保留错误提示给管理员。
- 证书发生变化：联系管理员确认，不要自行删除证书后盲目重装。
- 识别码无法登录：确认小写字母和数字格式；停用账号或管理员账号不能通过工程师入口登录。
- 已晋升专家但旧分机报 `The server returned an unexpected identity`：旧客户端可能只接受
  `ENGINEER` 返回值。安装配套 0.5.0 分机包；不要换识别码或新建账号规避角色检查。
  服务端支持该专家账号时，可先直接用浏览器打开服务器并输入原识别码。

# 分机使用指南

适用于 Windows 11。电脑上需要已有能正常使用的 CodeAgent；安装包不包含 CodeAgent 本体。
本连接器使用 CodeAgent 的启动参数，不要把 `codex.exe` 填入 CodeAgent 路径。

## 首次安装

先向管理员取得：安装 ZIP、服务器地址、个人访问令牌，以及 `root.crt` 和证书 SHA256 指纹。

1. **完整解压 ZIP**，不要直接在压缩包里运行。
2. 双击 `Trust Server Certificate.bat`，按提示填写 `root.crt` 的完整路径和管理员提供的 64 位指纹。使用公司已信任证书时跳过这一步。
3. 双击 `Install.bat`，桌面会出现 **GWAP CodeAgent**。
4. 双击桌面图标，填入服务器地址。弹出凭据窗口时，把个人令牌填入**密码**栏，用户名保持原值。
5. 如果提示找不到 CodeAgent，填写它的启动文件完整路径，例如 `C:\Tools\CodeAgent\codeagent.cmd`。

地址和令牌会保存在当前 Windows 用户下，以后直接打开桌面图标即可。

## 开始分析

先输入：

> 使用 gw-ap-debug 检查平台连接。

连通后输入：

> 使用 gw-ap-debug 分析 AP 离线问题。GW 日志在「完整路径」，AP 日志在「完整路径」。请创建案例、分析日志并生成报告，结论引用日志证据。

只有一份日志就只写一份。先确认公司允许这些日志由当前 CodeAgent 模型处理。
报告和历史案例也可以在浏览器中打开服务器地址查看；网页与 CLI 分别保存登录凭据。

## 修改知识

在网页知识库里修改并保存。自己的修订先用于自己新发起的综合诊断，已开始的诊断保留原版本。
需要让其他人使用时提交审核，管理员或原发布者任一通过后全员生效。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 浏览器也打不开 | 确认服务器已启动、地址正确，并连接公司网络 |
| 证书错误 | 重新核对服务器证书和指纹，完成首次安装第 2 步 |
| 令牌失效或地址更换 | 在解压目录打开 PowerShell，执行下方命令 |
| CodeAgent 自己也无法回答 | 检查 CodeAgent 登录和代理；平台安装包不会替你登录模型 |
| 普通 CodeAgent 窗口没有平台工具 | 从桌面 **GWAP CodeAgent** 图标启动 |

```powershell
.\Start.bat -Configure -ServerUrl https://192.168.1.100:8443
```

将示例地址换成管理员提供的地址，再重新填写令牌。

个人令牌不能共用，也不能把本机保存的配置复制给另一位同事。

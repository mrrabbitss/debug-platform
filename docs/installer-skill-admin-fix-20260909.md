# 0.5.1 内置组网 Skill 与管理员恢复修复

0.5.0 的交付遗漏：此前仅向开发实例导入了指定六文件组网包，没有将源包及初始化入口接入安装器。
原包清单和独立启动检查没有验证“安装后的新数据库有组网 Skill”，不能作为这项需求完成的证据。

## 实现范围

- 服务器构建新增 `--knowledge-bundle`，校验完整六文件和本地 Markdown 引用，将原 ZIP、原文件夹、逐文件哈希和用途装入程序目录。业务文档作为本地构建输入，不加入公开源码或数据库快照。
- 启动后仅对完全空的知识库使用既有一致备份、精确内容审批与持久化发布队列。审批明确标记 `INSTALLER_DEFAULT`，不伪造模型阅读回执。索引、正文和报告格式一次切换；中断不暴露部分默认 Skill。
- 初始导入只使用本地 Embedding。外部 Embedding 留给管理页面的显式确认；不调用 Chat 模型。
- 保留已有文档、草稿、发布/删除痕迹、全局经验和模板；记录保留决定，避免下次清空后补种。已完成、取消或失败的默认导入不会被启动程序自动重复创建。
- 管理页面显示初始化状态、源文件夹及操作编号。开始菜单增加内置组网文件夹及管理员恢复入口。
- 新初始管理员令牌七天有效；旧令牌原到期时间不变。取消后续每次启动仍把初始文件当成可用凭据的提示。
- 本机停服恢复只为已有、启用的 ADMIN 签发临时文件令牌；多管理员需明确用户名。不删除数据，不更改角色，不撤销其他有效令牌。细则见[管理员恢复说明](admin-recovery-20260909.md)。

# 管理员登录与本机恢复（2026-09-09）

适用范围是内网桌面服务器包的管理员令牌登录。工程师个人识别码只能创建或接续 `ENGINEER` 身份，不能用于管理员登录或恢复管理员权限。

0.5.1 首次安装只会生成一次 `config\bootstrap-token.txt`，有效期为 7 天。0.5.0 及更早的初始令牌仍按原来一天到期。升级和后续启动不会替换已有管理员账号、令牌或初始令牌文件。若初始令牌已过期，先正常停止服务器，再在开始菜单点击“恢复管理员访问（先停止服务器）”，或在安装目录双击 `Recover Administrator Access.bat`。

恢复入口使用与“GWAP 服务器”相同的当前 Windows 用户数据目录：默认 `%LOCALAPPDATA%\GWAPDebugServer`，如果启动时设置了 `GWAP_SERVER_DATA_ROOT`，恢复时也必须设置同一个值。它不会创建服务器、数据库、用户或管理员账号；数据库不存在、配置不匹配、服务器仍在运行，或已有恢复令牌仍有效时都会拒绝操作。
同一管理员的已过期、已撤销恢复令牌，或中断后未登记成功的恢复文件，可以在再次本机恢复时替换；其他账号或用途的令牌不会被替换。

默认只有恰好一个启用的 `ADMIN` 账号才会签发恢复令牌。多个启用管理员时，在安装目录的命令提示符中运行：

```bat
"Recover Administrator Access.bat" --username exact-admin-username
```

恢复令牌有效期为 7 天，可在 1 至 30 天之间显式设置，例如 `--expires-days 14`。令牌仅写入本机 `config\admin-recovery-token.txt`，不会显示在命令窗口、日志或审计记录中。用它从网页登录页的“管理员入口”登录后，应立即签发个人管理员令牌，确认可用，再撤销恢复令牌并删除该文件。

每次成功恢复都会写入 `auth.admin_recovery_token_issued` 审计事件，其中只保存账号、令牌名称、有效期和文件已写入状态，不保存令牌内容。

新建初始管理员时若在令牌文件落盘后、数据库提交前中断，下次会复用已落盘的完整令牌完成同一次初始化。
普通写入失败会清理本次产生的残缺文件，不影响已有凭据。

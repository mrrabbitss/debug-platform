# 准备服务器和分机

本次使用配套的 **0.3.3 内网专用包**，服务器和分机都要更新。

1. 停止旧服务器，保留业务目录和备份。
2. 在服务器运行 `GWAP-Debug-Server-Setup-0.3.3-x64.exe`，完成后启动桌面“GWAP 服务器”。
3. 服务器显示 `READY` 后，同事解压配套分机 ZIP，运行 `Install.bat`，输入个人识别码即可。

两端均已预置服务器地址。分机自动配置证书、获得工程师身份，不需要团队接入码或手动令牌。
代码仓库不保存公司内网地址；专用 EXE 和 ZIP 单独交付，不应使用旧版本目录中的通用分机 ZIP 替代。

详细操作见[服务器使用指南](服务器使用指南.md)和[分机使用指南](分机使用指南.md)。

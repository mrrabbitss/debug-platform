# 准备服务器

服务器使用离线 EXE 安装包，不需要克隆 `release` 分支，也不需要现场构建。

1. 将 `GWAP-Debug-Server-Setup-0.3.2-x64.exe` 复制到服务器。
2. 双击安装，完成后从桌面“GWAP 服务器”启动。
3. 按[服务器使用指南](服务器使用指南.md)填写地址、登录和添加同事。

安装包包含 Python、完整 Embedding/Reranker 模型及 HTTPS 网关。构建时使用的缓存和工具不需要复制到服务器。

之前新增的 `setup_server.bat` 和 `scripts/setup_lan_server.ps1` 已移除。旧仓库和缓存可以保留；如果已有业务数据，先按指南迁移，不要直接清理。

分机仍使用 `deploy/releases/20260907` 中的快速安装 ZIP 和[分机指南](分机使用指南.md)。

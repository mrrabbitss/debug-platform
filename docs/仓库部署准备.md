# 从 release 分支准备服务器

当前服务器已有 `artifacts\lan\server-pilot-20260907` 时，直接按[服务器使用指南](服务器使用指南.md)启动。
下面只用于新克隆的仓库，不要在正在使用的服务器目录中重新构建。

## 生成服务器运行目录

在 Windows 11 上准备 Python 3.12、Node.js 22.12 或更新版本和 Git。首次构建需要联网下载。
双击仓库根目录的 `setup_server.bat`，或在该目录的 PowerShell 中执行：

```powershell
.\setup_server.bat
```

脚本自动检查环境、安装依赖、准备模型并生成服务器目录。看到 `Setup complete` 后，
双击 `scripts\start_lan_server.bat` 启动；之后每天只用启动脚本。

Hugging Face 模型固定通过 `https://hf-mirror.com` 下载，不自动回退直连；文件仍按原清单校验。

某一步失败时会停止并显示步骤，处理错误后重新运行即可复用已下载的缓存。
已有完整服务器目录时只校验并提示启动；不会覆盖已有程序或业务数据。
此脚本不安装 Windows 服务，也不自动安装 Python、Node.js 或 Git。

模型文件和 Python/Node 运行时不存入 Git。下载地址、版本及哈希由
`scripts/model-runtime/model-assets.json`、`deploy/windows-server/runtime.lock.json` 和现有依赖锁文件固定。
详细构建说明见 [GGUF 构建文档](windows-offline-gguf-installer.md)。

## 分机文件

现成分机 ZIP 和两份使用指南在 `deploy/releases/20260907`。分机不需要构建代码。
要重新生成分机包，在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -B scripts/build_windows_client.py --output artifacts/lan/client-rebuild
```

输出目录中的 ZIP 可直接分发。服务器地址、证书和每人的访问令牌在部署后另行提供。

# 服务器使用指南

适用于 Windows 11 x64。安装包已包含 Python、Embedding、Reranker 和 HTTPS 网关，不需要克隆仓库、安装开发环境或下载模型。

## 安装和启动

1. 双击 `GWAP-Debug-Server-Setup-0.3.2-x64.exe`，按提示安装。
2. 双击桌面上的“GWAP 服务器”。首次输入服务器地址，例如 `https://192.168.1.100:8443`，将 IP 换成公司网卡的实际 IPv4 地址。
3. 等待窗口显示 `READY`。使用期间保持窗口打开，并关闭电脑自动睡眠。
4. 以后直接使用桌面快捷方式启动；停止时在窗口按 `Ctrl+C`，等待退出。

如果分机无法访问，在管理员 PowerShell 中放行端口：

```powershell
New-NetFirewallRule -DisplayName "GWAP HTTPS" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8443 -Profile Domain,Private -RemoteAddress LocalSubnet
```

端口不同请修改 `8443`。此规则允许同一子网；其他网段需另行放行。

## 登录和添加同事

开始菜单 → GWAP Debug Server →“打开数据目录”。以下路径均相对于这个目录。

1. 打开 `client-files\root.crt`，把证书安装到**当前用户 → 受信任的根证书颁发机构**。
2. 浏览器打开服务器地址，进入“安全与审计”（`/security`）。
3. 将 `config\bootstrap-token.txt` 中的初始令牌填入页面凭据栏。该令牌有效期为一天。
4. 为自己签发并保存新的管理员令牌，切换使用后撤销初始令牌。为同事创建用户，角色选 `ENGINEER`，勾选立即签发令牌。

给同事提供分机安装 ZIP、`client-files` 里的地址和证书文件，以及他自己的访问令牌。令牌单独发送，证书指纹另行核对。
不要发送 `config`、`gateway` 目录或管理员令牌。

## 数据和备份

数据默认保存在 `%LOCALAPPDATA%\GWAPDebugServer`。知识、案例、附件、配置和证书都在这里；不要删除。
启动失败时查看其中的 `logs\script-server.log`。

先停止服务器，再从开始菜单运行“备份服务器（先停止服务器）”。看到 `Backup verified` 后，备份在数据目录的 `backups` 中。完成后重新启动服务器。
建议每天使用结束后备份，并保留本次 EXE 安装包。当前不会自动执行定时备份；只有本机磁盘时，仍需预留后续异机备份。

## 更新或已有数据

更新前先停止服务器并备份，再运行新安装包。卸载程序不会删除上述数据目录。

旧脚本方式的数据仍在旧仓库的 `artifacts\lan\server-data`，安装包不会自动搬动它。
如果已有知识和案例，先停止旧服务器并备份。在 Windows 的“编辑账户的环境变量”中新建用户变量 `GWAP_SERVER_DATA_ROOT`，值填旧 `server-data` 的完整路径。注销并重新登录 Windows 后，再启动桌面快捷方式，即可继续使用原数据目录。不要直接搬动目录，已有配置包含绝对路径。

# 服务器使用指南

适用于当前这台 Windows 电脑。服务器用脚本运行，不安装服务。

## 首次启动

新克隆的仓库先准备 Python 3.12、Node.js 22.12+ 和 Git，再双击根目录 `setup_server.bat`，联网等待构建完成；已有运行目录时跳过。

1. 保留项目目录和 `artifacts\lan\server-pilot-20260907`，不要移动包内文件。
2. 用 `ipconfig` 查看公司网卡的 IPv4 地址，最好固定该地址。
3. 双击项目中的 `scripts\start_lan_server.bat`。首次按提示填写地址，例如 `https://192.168.1.100:8443`，将 IP 换成服务器实际地址。
4. 等待窗口显示 `READY`。运行期间保持窗口打开，并关闭电脑自动睡眠。

如果其他电脑无法访问，在管理员 PowerShell 中放行端口（填写的端口不是 8443 时，相应修改）：

```powershell
New-NetFirewallRule -DisplayName "GWAP HTTPS" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8443 -Profile Domain,Private -RemoteAddress LocalSubnet
```

## 登录和添加同事

以下路径都从项目目录算起。

1. 打开 `artifacts\lan\server-data\client-files\root.crt`，把证书安装到**当前用户 → 受信任的根证书颁发机构**。
2. 浏览器打开启动窗口显示的地址，进入“安全与审计”（`/security`）。
3. 打开 `artifacts\lan\server-data\config\bootstrap-token.txt`，将里面的令牌填入页面凭据栏。初始令牌有效期为一天。
4. 为自己签发并保存新的管理员令牌，切换使用后撤销初始令牌。为同事创建用户，角色选 `ENGINEER`，勾选立即签发令牌。

给每位同事发送：

- 分机安装 ZIP。
- `client-files` 中的服务器地址、`root.crt` 和 `root.crt.sha256`。
- 该同事自己的访问令牌，单独发送；令牌只显示一次。

不要发送 `config`、`gateway` 目录或管理员令牌。证书指纹请另行核对。

## 日常开关

- 启动：双击 `scripts\start_lan_server.bat`，地址会自动沿用。
- 停止：在启动窗口按 `Ctrl+C`，等待程序退出。
- 电脑重启后：重新运行启动脚本。
- 启动失败：查看 `artifacts\lan\server-data\logs\script-server.log`。

## 备份

先停止服务器，再在项目目录打开 PowerShell：

```powershell
.\scripts\start_lan_server.bat --backup
```

看到 `Backup verified` 后，备份位于 `artifacts\lan\server-data\backups`。完成后重新启动服务器。
建议每天结束使用后备份一次；此脚本模式不自动执行定时备份。

业务数据在 `artifacts\lan\server-data`，不要清理这个目录。备份包含知识、案例、附件和服务器配置，
需要同时保留当前服务器程序目录。只有本机备份无法应对整块磁盘损坏；有第二块盘或共享目录后，再复制一份备份过去。

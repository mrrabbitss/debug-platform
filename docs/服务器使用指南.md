# 服务器使用指南

本次内网专用安装包已包含 Python、完整 Embedding/Reranker、HTTPS 网关和服务器地址。

## 安装和启动

1. 如果旧服务器正在运行，先按 `Ctrl+C` 停止；已有业务数据先备份。
2. 双击 `GWAP-Debug-Server-Setup-0.3.3-x64.exe` 安装。
3. 双击桌面“GWAP 服务器”，等待 `READY`。首次地址已预置，之后沿用保存的配置。
4. 使用期间保持窗口打开，并关闭电脑自动睡眠；停止时按 `Ctrl+C` 等待退出。

安装包不会修改 Windows 网卡的 IP、子网掩码或网关。HTTPS 端口为 `8443`。
如分机无法访问，在管理员 PowerShell 中放行端口：

```powershell
New-NetFirewallRule -DisplayName "GWAP HTTPS" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8443 -Profile Domain,Private -RemoteAddress LocalSubnet
```

该规则允许同一子网；其他网段需另行放行。已有规则时无需重复添加。

## 同事接入

把配套的分机 ZIP 发给同事。服务器先保持运行，同事安装时输入“一位小写字母＋八位数字”的个人识别码即可。
账号自动开通为工程师，不需要你逐人创建、发团队接入码或分发令牌。
分机安装器自动配置公共证书，网页和 CLI 使用同一个账号。

同一码代表同一身份，也可以在另一台电脑接续使用。此方式不校验姓名或密码，适用于同事互信的内网。
个人修订仍先对自己生效；线上发布仍由管理员或原发布者任一审批。

## 管理员登录

开始菜单 → GWAP Debug Server →“打开数据目录”，查看 `config\bootstrap-token.txt`。
在网页登录页选择“管理员入口”，输入令牌；初始令牌有效期为一天。
进入“安全与审计”，为自己签发并保存长期管理员令牌，切换后撤销初始令牌。以后继续从管理员入口登录。
旧服务器升级后继续使用原管理员令牌，不会重新生成初始账号。

管理员可停用账号。停用后，该识别码无法再次自助登录。工程师入口不能取得管理员身份。

## 数据和备份

数据默认位于 `%LOCALAPPDATA%\GWAPDebugServer`，知识、案例、附件、配置和证书都在这里。不要删除。
启动错误见 `logs\script-server.log`。

先停止服务器，再从开始菜单运行“备份服务器（先停止服务器）”。看到 `Backup verified` 后，备份位于数据目录的 `backups`。完成后重新启动。
建议每天使用结束后备份，并保留当前 EXE；不会自动执行定时备份。程序更新或卸载不会删除数据目录。

## 接续旧脚本的数据

旧数据仍在旧仓库的 `artifacts\lan\server-data`。先停止旧服务器并备份。
在 Windows“编辑账户的环境变量”中新建用户变量 `GWAP_SERVER_DATA_ROOT`，值填旧 `server-data` 的完整路径。
注销并重新登录 Windows 后再启动桌面快捷方式，即可沿用原目录。不要直接搬动目录，已有配置包含绝对路径。

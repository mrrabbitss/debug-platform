# Evidence contract

For material conclusions use one of:

- `CONFIRMED`: direct evidence establishes the fact/root cause and no material contradiction remains.
- `PROBABLE`: evidence strongly supports the hypothesis but an important verification step remains.
- `UNKNOWN`: evidence is insufficient, conflicting or the relevant telemetry/source is missing.

Always cite concrete evidence IDs from the runtime bundle. Distinguish supporting and contradicting evidence. State missing information and a verification action when not confirmed.
